## Overview

Semantic UI React v4 uses **CSS custom properties** (CSS variables) for all design tokens. This enables runtime theming, dark mode, and easy customization — no build tools or preprocessors required.

## CSS Custom Properties

All design tokens are exposed as CSS custom properties. Override them to customize any aspect of the design:

```css
:root {
  --sui-color-primary: #e03997;
  --sui-color-secondary: #6435c9;
  --sui-font-family: 'Inter', sans-serif;
  --sui-border-radius: 8px;
}
```

Common token categories:

- `--sui-color-*` — Colors (primary, secondary, success, error, warning, info)
- `--sui-font-*` — Typography (family, size, weight, line-height)
- `--sui-spacing-*` — Spacing scale (xs, sm, md, lg, xl)
- `--sui-border-*` — Border radius and widths
- `--sui-shadow-*` — Box shadows

## ThemeProvider

The `ThemeProvider` component enables scoped theming via React Context and CSS classes:

```jsx
import { ThemeProvider } from 'semantic-ui-react'
import 'semantic-ui-react/styles/themes/dark.css'

function App() {
  return (
    <ThemeProvider theme="dark">
      <YourApp />
    </ThemeProvider>
  )
}
```

## Dark Mode

A built-in dark theme is available:

```jsx
import 'semantic-ui-react/styles/themes/dark.css'
```

Toggle it at runtime with ThemeProvider:

```jsx
import { ThemeProvider, Button } from 'semantic-ui-react'
import { useState } from 'react'

function App() {
  const [theme, setTheme] = useState('default')

  return (
    <ThemeProvider theme={theme}>
      <Button onClick={() => setTheme(t => t === 'default' ? 'dark' : 'default')}>
        Toggle Theme
      </Button>
      <YourApp />
    </ThemeProvider>
  )
}
```

## useTheme Hook

Access and control the current theme from any component:

```jsx
import { useTheme } from 'semantic-ui-react'

function ThemeToggle() {
  const { theme, setTheme } = useTheme()

  return (
    <button onClick={() => setTheme(theme === 'default' ? 'dark' : 'default')}>
      Current theme: {theme}
    </button>
  )
}
```

## Custom Themes

Create a custom theme by defining CSS custom properties in a class:

```css label=my-theme.css
.my-brand-theme {
  --sui-color-primary: #e03997;
  --sui-color-background: #fafafa;
  --sui-border-radius: 8px;
  --sui-font-family: 'Inter', sans-serif;
}
```

Apply it with ThemeProvider:

```jsx
import './my-theme.css'
import { ThemeProvider } from 'semantic-ui-react'

function App() {
  return (
    <ThemeProvider className="my-brand-theme">
      <YourApp />
    </ThemeProvider>
  )
}
```

## CSS Layers

All built-in CSS uses `@layer` for predictable cascade ordering:

```
sui.reset < sui.tokens < sui.base < sui.components < sui.utilities < sui.theme
```

Your custom CSS (without a `@layer`) will naturally override all Semantic UI styles. This makes customization straightforward — just write normal CSS.
